# Legacy scripts

One-off Playwright scripts and code fragments from before the project had a test suite. They print values and
save screenshots rather than assert, and some click fixed pixel positions. Kept for reference; the maintained
tests are `tests/unit` (`npm test`) and `tests/e2e` (`npm run test:e2e`).
They run from the project folder: `node tests/legacy/nopop_test.js`.
